# Commit Message Examples

- `feat(cart): add coupon field to checkout`
- `fix(auth): reject expired refresh token`
- `docs(readme): explain local setup steps`
- `refactor(catalog): extract price formatter`
- `chore(deps): update rector configuration`
- `feat(api)!: replace legacy order payload`

## Anti-examples

- `update`
- `misc`
- `fix stuff`
