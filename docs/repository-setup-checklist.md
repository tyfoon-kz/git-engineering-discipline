# Repository Setup Checklist

- I created the project folder `ecommerce-platform`.
- I entered the folder and confirmed the location with `pwd`.
- I ran `git init`.
- I created `README.md`.
- I created `.gitignore`.
- I checked the state with `git status`.
- I added the files with `git add README.md .gitignore`.
- I created the first commit with a meaningful message.

## Important notes

- `git init` creates a local repository. It does not publish the project.
- `.git` is the internal service folder where Git keeps local history and metadata.
