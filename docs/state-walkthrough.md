# State Walkthrough

## Working tree

At this point the file has changed in the project folder, but the change is not yet selected for the next commit.

## Staging area

After `git add`, the change becomes part of the staged set for the next commit.

## Repository

After `git commit`, the staged change becomes part of local history.

## HEAD

At this stage, `HEAD` is enough to understand as the pointer to the current place in the local history.
