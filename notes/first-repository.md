# Первый локальный repository

Repository отличается от обычной папки тем, что хранит не только текущие файлы, но и историю Git. Рабочие файлы лежат в корне проекта, а служебная база истории находится внутри `.git`. Если удалить `.git`, папка останется, но Git-история исчезнет.

Первый commit нужен не для галочки. Он фиксирует начальное состояние проекта, от которого дальше можно сравнивать изменения. Хороший первый commit обычно содержит понятные базовые файлы: `README.md`, `.gitignore` и `Makefile`.

Файл сначала может быть `untracked`: он есть на диске, но еще не включен в историю. Команда `git add` помещает выбранное содержимое в staging area, а `git commit` сохраняет подготовленное состояние в repository.

В этом repository базовая проверка вынесена в Make targets:

```text
make status -> git status --short
make diff   -> git diff --check и git diff --stat
make check  -> git status --short и git diff --check
```

Так проект продолжает привычку из Module 00: повторяемые команды должны иметь имена и храниться рядом с кодом.
