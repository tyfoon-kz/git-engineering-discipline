# Рабочий корень проекта

Repository для работы:

```text
git@github.com:student/ecommerce-platform.git
```

Review URL для Tyfoon:

```text
https://github.com/student/ecommerce-platform.git
```

Мой рабочий корень - папка проекта `ecommerce-platform`.
Перед командами я проверяю, что терминал открыт именно в этом проекте, а не в домашней папке, папке загрузок или соседнем checkout.

Команды ориентации:

```bash
pwd
ls -la
git status --short
```

`pwd` показывает текущую папку.
`ls -la` показывает файлы в этой папке, чтобы увидеть `README.md`, `.git` и будущий `Makefile`.
`git status --short` показывает состояние репозитория коротким форматом.

Правило для практики: сначала проверить место запуска, потом выполнять команду урока.
Правильная команда в неправильной папке все равно даст неправильный рабочий результат.
