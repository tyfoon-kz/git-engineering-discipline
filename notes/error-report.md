# Отчет об ошибке

Пример инженерного сообщения:

```text
Command: make check
Where: /Users/student/projects/ecommerce-platform
Error: make: *** No rule to make target `check'. Stop.
Checked: pwd показывает папку ecommerce-platform; ls показывает README.md, но Makefile отсутствует; git status --short работает
Next step: создать Makefile в корне проекта или проверить, не был ли он создан в родительской папке
```

Почему такой формат полезен:

```text
Command показывает точную команду.
Where показывает место запуска.
Error сохраняет настоящий текст ошибки.
Checked показывает уже проверенные гипотезы.
Next step показывает текущую инженерную догадку.
```

Такой отчет помогает наставнику увидеть слой проблемы: shell, Git, Make, SSH, GitHub или текущая папка.
Он лучше, чем сообщение "не работает", потому что другой человек может воспроизвести ситуацию и быстро предложить следующий шаг.
