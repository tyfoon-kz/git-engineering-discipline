# ecommerce-platform

Учебный репозиторий для e-commerce проекта, в котором команда постепенно собирает каталог, корзину, заказы, оплату и административный контур.

## Что появится дальше

- `catalog` — структура каталога товаров и категорий;
- `cart` — базовая логика корзины;
- `orders` — оформление и хранение заказов;
- `payments` — контур платежей и статусов;
- `docs` — инженерные заметки по устройству проекта.
