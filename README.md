# Ecommerce Platform

Учебный репозиторий для будущей e-commerce платформы.

## Назначение проекта

Проект создается как база для интернет-платформы, в которой позже появятся:
- каталог товаров;
- корзина;
- оформление заказа;
- платежный поток;
- административная панель.

## Цель первого состояния

На этом этапе репозиторий фиксирует осмысленную стартовую точку:
- понятное описание проекта;
- базовые правила игнорирования лишних файлов;
- чистую основу, от которой можно продолжать разработку.
