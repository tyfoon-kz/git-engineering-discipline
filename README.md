# Git Engineering Discipline Repo

Этот репозиторий используется как полигон для домашних заданий и эталонных решений курса.

## Принцип

- `main` хранит базовое состояние;
- одна домашка = одна ветка;
- в ветке лежит эталонное решение конкретного задания;
- позже сюда добавим экзаменационный сценарий.
